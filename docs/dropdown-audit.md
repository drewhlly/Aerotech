# Controlled input audit

Select controls are appropriate for portal role, country, plan, billing country, salary band, payroll run, employee, manager, workplace, employment type, application stage, vacancy approval decision, rejection reason, review rating, verified goal progress, document credential type, document review status, survey cadence, exit reason, ticket status, gender, marital status and rent-relief review status.

This release adds or retains those controls at their corresponding workflows. Names, email addresses, NIN/BVN, addresses, agreement text, review evidence, goals and support descriptions remain text inputs. Dates/months retain native date/month controls; amounts retain decimal numeric inputs. Department names and job titles support organisation-specific values rather than a fixed global list. Existing profile values remain selectable when they differ from current standard options.

Fixed salary allocation is a disclosed company template, not a claim about country law. Tax engines stay restricted to configured jurisdictions. Unpriced country currencies require a quote rather than fabricated exchange rates.
